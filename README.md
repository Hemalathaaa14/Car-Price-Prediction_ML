# 🚗 Car Price Prediction

## Project Description
This project predicts the selling price of used cars using Machine Learning and Python.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Workflow
1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Data Preprocessing
5. Exploratory Data Analysis (EDA)
6. Model Training
7. Price Prediction
8. Model Evaluation

## Objective
To predict used car prices based on different car features.

## Project Files
- `car_price_prediction.ipynb` – Jupyter Notebook
- `car_data.csv` – Dataset

## Conclusion
This project helps estimate used car prices using Machine Learning techniques.
